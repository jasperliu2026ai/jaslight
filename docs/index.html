Setup

三步配置监控源

JasLight 靠读日志工作，所以要先告诉它日志在哪

1

🔍 自动探测（最快）

打开 偏好设置 → 监控源 → 自动探测本机 AI 工具，它会扫描常见路径，列出所有找到日志的工具，点击即添加。首次启动时也会自动跑一次。

如果你的工具被探测到了，到这一步就结束了。

2

📋 从模板添加

在 从模板添加 区域点击工具名（Claude Code / Cursor / Codex / Trae / CodeBuddy …），会添加一份预置配置。

添加后展开卡片，点 测试路径 验证 —— 会显示实际解析到的文件、大小和修改时间。路径不对就手动改。

3

⚙️ 完全自定义（任意工具）

选 自定义源 模板，填四项：日志路径、进程名、应用名、四条状态正则。

路径占位符：

占位符含义例子

找日志特征的方法：一边用 AI，一边跟踪日志，记下四个时刻打印了什么 —— 你发消息时、AI 调工具时、弹出「允许」时、回复结束时。

# macOS / Linux
tail -f "路径/到/日志.log"

# Windows PowerShell
Get-Content "路径\到\日志.log" -Wait -Tail 20

多个候选词用 | 分隔，例如 tool_call|function_call|invoke_tool。不确定就先用默认的通用规则 —— 对大多数 Agent 工具能覆盖 60% 以上状态。
